# DTO Architecture V3 - Änderungen und Aktualisierungen

**Datum:** 2025-12-28  
**Status:** Draft für Integration in DTO_ARCHITECTURE.md

---

## 🔄 Hauptänderungen gegenüber V2

### 1. Interface-basierte Generierung (nicht Class-basiert)

**Alt (V2):**
```csharp
[GenerateDto]
public class PlayerEntity : CombatEntity
{
    public string DisplayName { get; set; }
}
// Generiert: PlayerEntityDto mit FromPlayerEntity() Methode
```

**Neu (V3):**
```csharp
[GenerateDto(DtoName = "CharacterEntityDto")]
public interface ICharacterEntity : ICombatEntity
{
    string DisplayName { get; init; }
    Position Position { get; set; }
}
// Generiert: CharacterEntityDto : ICharacterEntity
```

**Warum?**
- Interfaces sind shared zwischen Server und Client
- Klare Contracts für Netzwerk-Daten
- Ermöglicht polymorphe Serialisierung

---

### 2. Extension Methods statt Static Methods

**Alt (V2):**
```csharp
var dto = PlayerEntityDto.FromPlayerEntity(entity);
var entity = dto.ToPlayerEntity();  // oder dto.ApplyTo(entity)
```

**Neu (V3):**
```csharp
var dto = entity.ToDto();  // Extension Method
// Keine ApplyTo() - DTOs sind read-only nach Deserialisierung
```

**Generierte Extension Methods:**
- `ToDto()` - Konvertiert Entity → DTO
- `ToDtoList()` - Konvertiert List<Entity> → List<DTO>
- `ToUnionDto()` - Konvertiert Entity → Union DTO (bei Polymorphismus)
- `ToUnionDtoList()` - Konvertiert List<Entity> → List<Union DTO>

---

### 3. Union Types für Polymorphismus

**Neu in V3:** `[GenerateDtoUnion]` und `[DtoUnionMember]`

```csharp
// Root Interface
[GenerateDto(DtoName = "EntityDto")]
[GenerateDtoUnion(UnionName = "EntityDtoUnion", Namespace = "Mmo.Shared.Entities.Dtos")]
public interface IEntity
{
    Guid PersistentId { get; init; }
    Position Position { get; set; }
}

// Derived Interface
[GenerateDto(DtoName = "CharacterEntityDto")]
[DtoUnionMember(0, typeof(IEntity))]
public interface ICharacterEntity : ICombatEntity
{
    Guid CharacterId { get; init; }
}

[GenerateDto(DtoName = "NpcEntityDto")]
[DtoUnionMember(1, typeof(IEntity))]
public interface INpcEntity : ICombatEntity
{
    int NpcTemplateId { get; init; }
}
```

**Generiert:**
```csharp
// EntityDtoUnion.g.cs
[Union(0, typeof(CharacterEntityDto))]
[Union(1, typeof(NpcEntityDto))]
public interface EntityDtoUnion { }

// CharacterEntityDto implementiert: ICharacterEntity, EntityDtoUnion
// NpcEntityDto implementiert: INpcEntity, EntityDtoUnion
```

**Verwendung:**
```csharp
List<IEntity> entities = zone.GetEntities();
List<EntityDtoUnion> dtos = entities.ToUnionDtoList();
// Polymorphe Serialisierung mit MessagePack Union
```

---

### 4. Set vs Init Accessor Logic

**Wichtig:** Der Generator respektiert die Accessor-Typen des Interfaces!

```csharp
public interface IEntity
{
    Guid PersistentId { get; init; }  // DTO: { get; init; }
    Position Position { get; set; }    // DTO: { get; set; }
    EntityType Type { get; }           // DTO: { get; init; }
}
```

**Regel:**
- Interface hat `{ get; set; }` → DTO bekommt `{ get; set; }` (mutable)
- Interface hat `{ get; init; }` → DTO bekommt `{ get; init; }` (init-only)
- Interface hat nur `{ get; }` → DTO bekommt `{ get; init; }` (readonly after construction)

**Warum wichtig?**
- Erfüllt Interface-Contract
- Ermöglicht Mutability wo nötig (z.B. Position-Updates)
- Verhindert Compilation Errors: `'CharacterEntityDto' does not implement interface member 'IEntity.Position.set'`

## 📝 Neue Attribute

### `[GenerateDtoUnion]`

Markiert ein Interface als Wurzel einer Union-Hierarchie.

**Properties:**
- `UnionName` (string?): Name des Union-Interfaces (default: "{InterfaceName}DtoUnion")
- `Namespace` (string?): Namespace für Union (default: "{Source}.Dtos")

**Beispiel:**
```csharp
[GenerateDtoUnion(UnionName = "EntityDtoUnion", Namespace = "Mmo.Shared.Entities.Dtos")]
public interface IEntity { }
```

### `[DtoUnionMember]`

Markiert ein Interface als Member einer Union.

**Parameter:**
- `index` (int): Union-Index für MessagePack
- `rootType` (Type): Das Root-Interface (mit [GenerateDtoUnion])

**Beispiel:**
```csharp
[DtoUnionMember(0, typeof(IEntity))]
public interface ICharacterEntity : IEntity { }
```

### `[DtoImplements]`

**Unverändert** - Fügt zusätzliche Interfaces zum DTO hinzu.

### `[DtoIgnore]`

**Unverändert** - Schließt Properties vom DTO aus.

### `[DtoProperty]`

**Unverändert** - Konfiguriert einzelne Properties.

## 🔧 Generierte Code-Struktur

### Beispiel: CharacterEntityDto

```csharp
// <auto-generated/>
// Generated by Mmo.Generators.DtoGenerator
// Source: Mmo.Shared.Character.Interfaces.ICharacterEntity

#nullable enable

using MessagePack;
using Mmo.Shared.Character.Interfaces;
using Mmo.Shared.Entities.Dtos;

namespace Mmo.Shared.Character.Interfaces
{
    [MessagePackObject]
    public sealed class CharacterEntityDto : ICharacterEntity, EntityDtoUnion
    {
        [SerializationConstructor]
        public CharacterEntityDto() { }

        public CharacterEntityDto(ICharacterEntity source)
        {
            ArgumentNullException.ThrowIfNull(source);
            PersistentId = source.PersistentId;
            Position = source.Position;
            DisplayName = source.DisplayName;
            // ... alle Properties
        }

        [Key(0)]
        public Guid PersistentId { get; init; }

        [Key(1)]
        public Position Position { get; set; }  // 'set' weil Interface 'set' hat

        [Key(2)]
        public string DisplayName { get; init; }  // 'init' weil Interface 'init' hat

        // ... weitere Properties
    }
}
```

### Beispiel: Extension Methods

```csharp
// CharacterEntityDtoExtensions.g.cs
public static class CharacterEntityDtoExtensions
{
    public static CharacterEntityDto ToDto(this ICharacterEntity source)
    {
        ArgumentNullException.ThrowIfNull(source);
        return new CharacterEntityDto(source);
    }

    public static List<CharacterEntityDto> ToDtoList(this IEnumerable<ICharacterEntity> source)
    {
        ArgumentNullException.ThrowIfNull(source);
        return source.Select(x => x.ToDto()).ToList();
    }
}
```

### Beispiel: Union Extension Methods

```csharp
// EntityDtoUnionExtensions.g.cs
public static class EntityDtoUnionExtensions
{
    public static EntityDtoUnion ToUnionDto(this IEntity source)
    {
        ArgumentNullException.ThrowIfNull(source);
        
        return source switch
        {
            ICharacterEntity x => x.ToDto(),
            INpcEntity x => x.ToDto(),
            _ => throw new ArgumentException($"Unknown IEntity type: {source.GetType().Name}")
        };
    }

    public static List<EntityDtoUnion> ToUnionDtoList(this IEnumerable<IEntity> source)
    {
        ArgumentNullException.ThrowIfNull(source);
        return source.Select(x => x.ToUnionDto()).ToList();
    }
}
```

## 💻 Verwendungsbeispiele

### Server → Client: Entity zu DTO

```csharp
// Server-Side
CharacterEntity entity = new CharacterEntity(...);
CharacterEntityDto dto = entity.ToDto();

var message = new ZoneState
{
    Entities = entities.ToUnionDtoList()  // Polymorphe Liste
};

byte[] bytes = MessageSerializer.Serialize(message);
```

### Client: DTO empfangen

```csharp
// Client-Side
var message = MessageSerializer.Deserialize<ZoneState>(bytes);

foreach (EntityDtoUnion entityDto in message.Entities)
{
    // Polymorphe Deserialisierung
    if (entityDto is CharacterEntityDto character)
    {
        Console.WriteLine($"Player: {character.DisplayName}");
        character.Position = new Position(x, y);  // Mutable!
    }
    else if (entityDto is NpcEntityDto npc)
    {
        Console.WriteLine($"NPC: {npc.DisplayName}");
    }
}
```

## 🔍 Migration von V2 zu V3

### 1. Klassen zu Interfaces

**Vorher:**
```csharp
[GenerateDto]
public class PlayerEntity
{
    public string Name { get; set; }
}
```

**Nachher:**
```csharp
[GenerateDto(DtoName = "PlayerEntityDto")]
public interface IPlayerEntity
{
    string Name { get; init; }
}

public class PlayerEntity : BaseEntity, IPlayerEntity
{
    public string Name { get; set; }
}
```

### 2. Static Methods zu Extension Methods

**Vorher:**
```csharp
var dto = PlayerEntityDto.FromPlayerEntity(entity);
dto.ApplyTo(existingEntity);
```

**Nachher:**
```csharp
var dto = entity.ToDto();
// Kein ApplyTo() mehr - DTOs sind immutable nach Deserial.
```

### 3. Polymorphe Listen

**Vorher:**
```csharp
List<IEntityDto> entities = new();
// Kein echtes Union-Pattern
```

**Nachher:**
```csharp
List<EntityDtoUnion> entities = serverEntities.ToUnionDtoList();
// MessagePack Union mit Type-Safety
```

## ✅ Best Practices V3

### DO ✅

```csharp
// Interfaces mit klaren Accessor-Typen
public interface IEntity
{
    Guid PersistentId { get; init; }  // Immutable
    Position Position { get; set; }    // Mutable
}

// Union für Polymorphismus
[GenerateDtoUnion]
public interface IEntity { }

[DtoUnionMember(0, typeof(IEntity))]
public interface ICharacterEntity : IEntity { }

// Extension Methods verwenden
var dtos = entities.ToUnionDtoList();
```

### DON'T ❌

```csharp
// Keine Klassen für DTO-Generation (V2-Pattern)
[GenerateDto]
public class Entity { }  // ❌

// Kein FromEntity() oder ApplyTo() manuell implementieren
var dto = EntityDto.FromEntity(entity);  // ❌ (Auto-generiert)
dto.ApplyTo(entity);  // ❌ (Existiert nicht mehr)

// Keine falsche Union-Hierarchie
[DtoUnionMember(0, typeof(IWrongRoot))]  // ❌ Root muss [GenerateDtoUnion] haben
```
